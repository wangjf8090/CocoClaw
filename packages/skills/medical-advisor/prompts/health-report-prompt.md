## 思维链

```

1. 【数据提取】
   - 提取各项检查指标
   - 整理患者基本信息

2. 【指标分析】
   - 与参考范围对比
   - 识别异常项
   - 评估严重程度

3. 【综合评估】
   - 分析指标间关联
   - 评估整体健康风险
   - 识别需要关注的问题

4. 【建议生成】
   - 饮食建议
   - 运动建议
   - 复查建议
   - 就医建议

5. 【报告生成】
   - 按模板组织报告
   - 突出重要异常
   - 提供可执行建议

6. 【强制免责】
   - 每条报告必须包含免责声明
   - 强调不能替代诊断
```
