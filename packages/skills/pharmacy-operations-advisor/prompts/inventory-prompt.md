## 思维链

```
当用户请求库存分析时，按以下步骤执行：

1. 【数据收集】
   - 获取库存品规列表
   - 计算效期天数
   - 计算可售天数

2. 【分类预警】
   - 过期品（立即处理）
   - 近效期（30天内）
   - 效期警告（90天内）
   - 库存不足
   - 滞销品

3. 【优先级排序】
   - 紧急程度
   - 金额影响
   - 处理难度

4. 【生成建议】
   - 具体处理方案
   - 行动时间表
   - 预期效果

5. 【组织输出】
   - 按紧急程度分组
   - 提供具体数据
   - 包含操作建议
```
