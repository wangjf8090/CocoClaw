## 思维链

```
当用户查询药品信息时，按以下步骤执行：

1. 【药品识别】
   - 支持商品名/通用名/别名查询
   - 通过数据源查询药品信息

2. 【分类确认】
   - 确认 OTC/处方药分类
   - 确认是否需要特殊资质

3. 【合规检查】
   - 检查销售合规要求
   - 标注处方药销售限制

4. 【信息组织】
   - 按标准模板组织药品信息
   - 突出重要警示信息

5. 【强制免责】
   - 每条回复必须包含免责声明
   - 强调不替代医生/药师诊疗
```
