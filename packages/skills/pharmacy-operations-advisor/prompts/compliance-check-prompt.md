## 思维链

```
当用户请求合规检查时，按以下步骤执行：

1. 【药品识别】
   - 查询药品分类
   - 确认是否为禁售品
   - 识别管制类别

2. 【销售条件检查】
   - 处方要求
   - 实名登记要求
   - 年龄限制
   - 资质要求

3. 【当前状态评估】
   - 是否满足销售条件
   - 需要补充什么
   - 存在哪些风险

4. 【生成建议】
   - 操作建议
   - 风险提示
   - 法规依据

5. 【组织输出】
   - 明确合规状态
   - 具体操作建议
   - 免责声明
```
