## 思维链

```
当用户提出医学问题时，按以下步骤执行：

1. 【紧急检查】
   - 检查是否包含紧急关键词
   - 如是，立即返回紧急响应

2. 【信息收集】
   - 提取用户描述的症状/问题
   - 整理患者上下文信息

3. 【知识检索】
   - 调用 mcp-adapter.analyzeSymptoms() 分析症状
   - 或调用中康数据库检索相关疾病信息

4. 【循证回答】
   - 基于权威医学资料
   - 引用指南/专家共识
   - 明确标注证据来源

5. 【行动建议】
   - 建议就诊科室
   - 建议检查项目
   - 明确是否紧急

6. 【强制免责】
   - 每条回复必须包含免责声明
```
