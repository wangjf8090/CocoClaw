# SelfClaw v3.6.0: 领域 Skill 工厂 + Skill Cleaner 独立化

## 概述

**版本升级**: SelfClaw v3.5.0 → v3.6.0

v3.6.0 在 v3.5.0 基础上新增**领域 Skill 工厂核心框架**（skill-factory-core）和**首批垂类 Skill 模板**（金融/医疗），同时规划 Skill Cleaner 独立产品的商业闭环架构。

### v3.5.0 现有能力
- 7 大核心模块：orchestrator / audit / optimize / lifecycle / compliance / template / observability
- 5 个垂类 Skill：agent-memory-system-guide / agent-self-evolution / ai-text-detox / news-aggregator-skill / stock-analysis

### v3.6.0 新增能力
- **领域 Skill 工厂核心框架**：垂类识别引擎 + 模板匹配器 + 封装构建器
- **首批垂类 Skill 模板**：wind-stock-analyzer（金融）+ zhongkang-medical-advisor（医疗）
- **Skill Cleaner 商业闭环**：3 档定价 + HMAC-SHA256 签名 + 4 垂类审计维度

---

## v3.6.0.1 修订（2026-06-14）

根据市场对比分析，对医疗模板进行了去中康化重构：

| 修订项 | 原内容 | 新内容 |
|--------|--------|--------|
| Skill 名称 | `zhongkang-medical-advisor` | `medical-advisor` |
| 数据源 | 单一中康 API | 多数据源可插拔架构 |
| 定位 | 绑定中康 | 开发者级医疗 Skill 工厂 |

**医疗模板新文件结构**：
```
packages/skills/medical-advisor/
├── SKILL.md                    # v1.1.0 去中康化版
├── mcp-adapter.ts             # 向后兼容 shim
```

### 4. 4 垂类审计维度扩展

| 领域 | 审计标准 | 合规要求 |
|------|----------|----------|
| 金融 | SEC (美国证券交易委员会) | 投资建议合规、风险披露 |
| 医疗 | HIPAA (健康保险流通与责任法案) | 患者隐私保护、数据安全 |
| 学术 | DOI / PMID | 引用溯源、学术诚信 |
| 法律 | GDPR (通用数据保护条例) | 数据最小化、同意管理 |

### 5. P0 商业闭环架构（Skill Cleaner 独立化）

- **3 档定价**：免费 / 专业版（¥99-199/月）/ 企业版（¥999-2999/月）
- **HMAC-SHA256 签名**：API 安全认证
- **REST API**：标准化接口设计
